📱 Mobile vs Desktop Interactions

Touch-First Interaction Patterns

Mobile (Primary)
• Tap feedback: Scale down (0.95-0.98)
• No hover states
• Larger touch targets (44x44px min)
• Swipe gestures for actions
• Long press for options
Desktop (Enhancement)
• Hover: Subtle elevation/color
• Cursor changes
• Smaller click targets OK
• Right-click menus
• Keyboard shortcuts
Universal Patterns
• Visual feedback within 100ms
• Clear active/pressed states
• Consistent animations
• Accessible focus indicators
• Loading states

    📱 Mobile-Specific Design Decisions

    Touch Targets
    All interactive elements are minimum 44x44px for comfortable tapping
    Feedback Timing
    Immediate visual feedback (scale/opacity) within 100ms of touch
    Gestures
    Swipe to dismiss, pull to refresh, long press for options

    Why Hover Doesn't Matter on Mobile:

    • Touch screens don't have hover states - finger is either touching or not
    • We use :active states for immediate touch feedback
    • Scale transforms (0.95-0.98) provide satisfying tactile response
    • Shadow reduction on press mimics physical button depression
    • Desktop hover effects are purely progressive enhancement

    Component Specifications

    Buttons

    • Shape: Fully rounded (border-radius: 100px)
    • Padding: 16px vertical, 36px horizontal
    • Typography: Bold (700), 16px
    • Colors: Gradient backgrounds for depth
    • Mobile feedback: scale(0.95) on press
    • Desktop enhancement: translateY(-2px) on hover
    • Emergency button: Pulsing animation

    Cards

    • Background: Solid white (NO gradient on hover)
    • Border: 1px solid rgba(20, 184, 166, 0.2)
    • Border-radius: 24px
    • Shadow: 0 4px 20px rgba(0,0,0,0.08)
    • Mobile feedback: scale(0.98) on press
    • Desktop hover: Subtle border color change + slight elevation
    • Glass variant: backdrop-filter: blur(20px) for premium feel

    Input Fields

    • Shape: Fully rounded (border-radius: 50px)
    • Border: 3px solid #14B8A6
    • Padding: 16px vertical, 24px horizontal
    • Focus state: Border changes to #A78BFA + scale(1.02)
    • Placeholder: Light gray (#BDC3C7)
